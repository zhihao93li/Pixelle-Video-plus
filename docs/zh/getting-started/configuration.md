# 配置

正式配置入口位于控制台的「设置」。每个分区独立保存，失败会在当前分区显示。

## 首次配置顺序

1. **项目**：创建或选择项目，设置默认生产配方。
2. **AI 与语音**：配置文案模型、TTS 模式、音色与工作流。
3. **生成引擎**：配置本地 ComfyUI 或 RunningHub，并执行连接诊断。
4. **发布与存储**：配置输出目录、发布平台和相关凭据。
5. **配方**：确认当前项目需要的配方已启用，并按需设置配方默认值。

## 配置来源

运行时配置保存在本地 `config.yaml` 和后端数据目录中。正式配置入口是 React
控制台；迁移期不要同时使用 legacy Streamlit 修改配置，以免旧进程覆盖新配置。
不要在前端代码中写密钥或业务默认值。

生成设置的优先级固定为：

```text
项目默认 → 配方生效默认 → 本次覆盖
```

本次没有修改的字段不会作为覆盖项提交。

## 服务诊断

设置概览会分别报告 LLM、TTS、媒体生成、FFmpeg、存储和发布能力。错误不会被当作空配置或成功状态。真实生成前应先解决对应分区显示的阻断项。
