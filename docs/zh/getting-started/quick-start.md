# 快速开始

## 启动服务

在仓库根目录启动 API：

```bash
uv run uvicorn api.app:app --host 127.0.0.1 --port 8000
```

另开终端启动控制台：

```bash
cd apps/console
npm install
npm run dev
```

打开 `http://127.0.0.1:5173`。

## 首次配置

1. 打开「设置」。
2. 在「项目」中创建或选择项目。
3. 在「AI 与语音」中配置内容模型与语音服务。
4. 在「生成引擎」中检查本地或云端生成连接。
5. 在「配方」中确认项目需要的生产配方已启用。

各分区独立保存。页面顶部诊断会显示仍需处理的连接问题。

## 生成第一份作品

1. 打开「快速生产」。
2. 选择视频、图集、长文或专用视频生产方式。
3. 选择配方并进入生成页。
4. 输入文案、选题或素材。
5. 检查右侧预估与本次设置，点击「开始生成」。
6. 在右侧或「任务」页面查看进度。
7. 完成后在「作品库」预览结果并进入发布。

批量不是独立页面。在支持批量的配方生成页中切换到「批量」即可。

## 单进程正式入口

需要模拟 Docker 或 Windows 整合包时，先构建 React，再由 FastAPI 同源托管：

```bash
./start_web.sh
```

legacy Streamlit 已冻结，仅在迁移排查时手动运行，不再作为默认或正式入口。

API 文档默认位于 `http://127.0.0.1:8000/docs`。
