# Web 控制台

Pixelle 控制台围绕项目组织内容生产。桌面端使用左侧主导航；页面标题、项目切换和主题控制位于统一壳层中。

## 工作台

工作台按生命周期展示内容：选题、草稿、审核、生产、发布和数据。打开内容详情可以编辑语言版本、确认草稿、提交生产并查看当前唯一下一动作。

## 快速生产

快速生产先按产物选择生产方式，再选择配方：

- 视频：文案或选题生成、素材成片
- 图集：封面和多页图片
- 长文：结构化文本
- 专用视频：图生视频、动作迁移、数字人
- 审核流程：多语言草稿审核后统一提交

生成页左侧是输入和本次设置，右侧依次显示预估、任务进度和结果。批量在支持它的生成页中切换，不使用独立入口。

## 任务

任务以一次提交为主体。列表展示总体状态和进度；详情展示子任务、失败原因以及当前可用的取消或重试动作。

## 作品库

作品库支持关键词、产物类型、状态和排序筛选。选择作品后可以预览视频、图集或长文，查看生产信息、下载结果并在满足条件时进入发布。

## 设置

设置按 URL 分区：

- 概览
- 项目
- AI 与语音
- 生成引擎
- 发布与存储
- 配方
- 帮助

每个配置分区独立保存。未保存更改会被标记，离开前会给出提示。

## 状态与失败恢复

加载失败、无数据和过期数据是不同状态。页面会在出错区域显示原因与恢复动作，不会把错误伪装成空列表或成功结果。
