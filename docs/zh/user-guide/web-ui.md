# Web 控制台

Pixelle 控制台围绕项目组织内容生产。桌面端使用左侧主导航；页面标题、项目切换和主题控制位于统一壳层中。

## 工作台

工作台按确定状态展示生产任务：待你处理、进行中、异常和已产出。打开任务卡直接进入唯一详情页：顶部处理当前最重要的操作，下方按时间倒序查看同一任务的真实输出、失败与重试记录。

## 快速生产

快速生产先按产物选择生产方式，再选择模板：

- 视频：文案或选题生成、素材成片
- 图集：封面和多页图片
- 长文：结构化文本
- 专用视频：图生视频、动作迁移、数字人

生成页左侧是输入和本次设置，提交后进入工作台任务详情查看进度、人工确认、失败恢复和结果。批量在支持它的生成页中切换；每一项建立独立任务，不建立批次总状态。

## 作品库

作品库支持关键词、产物类型、状态和排序筛选。选择作品后可以预览视频、图集或长文，查看生产信息、下载结果并在满足条件时进入发布。

## 设置

设置按 URL 分区：

- 概览
- 项目
- AI 与语音
- 生成引擎
- 发布与存储
- 模板
- 帮助

每个配置分区独立保存。未保存更改会被标记，离开前会给出提示。

## 状态与失败恢复

加载失败、无数据和过期数据是不同状态。页面会在出错区域显示原因与恢复动作，不会把错误伪装成空列表或成功结果。

服务重启后，已经完成或失败的任务状态会被保留；当时尚未完成的任务会显示为“已中断”，需要用户明确重试。
