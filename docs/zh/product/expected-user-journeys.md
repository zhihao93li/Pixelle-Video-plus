# Pixelle 控制台 · 预期用户动线说明

日期：2026-07-05
适用版本：React 控制台（生产提交层统一后）。本文描述**预期动线**——每条动线的入口、逐步操作、系统反馈、完成判据。可直接用作验收脚本和新人上手说明。

**用户设定**：单人内容运营（当前 PetWoods，小红书主渠道 + 多语言出海），日常工作是持续出片、发布、看数据。Agent（Ops/Codex）通过同一套 API 出片，与人共享模板配置。

---

## 0. 全局结构

侧边导航四区（窄屏为顶部横滑）：

| 区 | 路由 | 职责 |
| --- | --- | --- |
| 新建视频 | `/create` | 唯一创作入口：按内容来源选择方式 |
| 任务 | `/tasks` | 全局任务中心：进行中角标、进度、取消、完成跳转 |
| 作品库 | `/library` | 成片网格、搜索筛选、详情、发布、删除 |
| 设置 | `/settings` | 系统设置 / 模板状态（含默认配置编辑）/ 帮助，三个 tab |

全局约定：URL 可刷新恢复、可回退；任务在任何页面都持续轮询，终态弹 toast；破坏性操作一律确认弹窗；工程信息（任务 ID、路径）收在「技术详情」折叠区。

## 1. 首次使用动线（一次性）

**目标**：从空配置到能出第一条片。

1. 进入 设置 → 系统设置。顶部诊断面板逐项亮灯（LLM、ComfyUI/RunningHub、Fish Audio、Buffer、COS）。
2. 填 AiHubMix Key → 「加载模型」→ 选默认模型 → 「测试连接」变绿。
3. 按需配 ComfyUI URL / RunningHub Key、Fish Audio Key + 默认 reference_id（多语言审核流依赖此默认值）、Buffer Token → 「拉取 Channels」自动填平台。
4. 「项目默认模板」区：确认项目与默认生产模板（新建视频与审核/批量的默认选中项都来自它）。
5. （可选）打开「专家模式」开关——日常关闭；开启后生成页与提交面板出现 workflow 级覆盖项，模板状态页可编辑模板默认配置。

**完成判据**：诊断面板绿灯；「配置可用」徽章亮起。

## 2. 核心动线 A：单条生成（文字 → 成片）

**入口**：新建视频 → 「从文字开始」组 → 选卡片（已有文案 / 只有选题）。

1. 落到 `/create/generate/:templateId`，顶部一行模板摘要（名称 + 预计耗时 + 描述），右侧「更换模板」开抽屉可切换；跨入口模板会先弹确认。
2. 主输入框填文案或选题（空态有 placeholder 和「填入示例」；草稿自动本地保存，刷新不丢）。
3. （可选）展开高级设置三分组：**内容结构**（标题、分镜数/拆分方式、提示词规则）→ **画面风格**（画面模板 + 「预览画面」渲染示例帧、模板参数、提示词前缀/视觉上下文）→ **声音与音乐**（声音 + 「试听」、语速滑杆、BGM 选择/上传/音量/模式）。专家模式额外出现 workflow 覆盖与媒体预览（标注消耗额度）。
4. 点「开始生成」（不可用时按钮下方一行灰字说明原因）。
5. 右栏任务状态卡出现进度条与阶段文案；同时任务进入全局任务中心（侧边栏角标 +1）。此时**可以离开页面**。
6. 完成：toast「视频生成完成」；结果卡自动加载成片播放器 + 质量检查 + 素材清单。
7. 点结果卡主按钮「前往发布」→ 跳转作品库并自动选中该片（衔接动线 F）。

**完成判据**：能播放成片；任务中心该条为「已完成」。
**失败路径**：任务状态卡红色错误（后端原文 + 模板的排查指引）；toast「生成失败」；可直接改参数重新提交。

## 3. 动线 B：素材成片（照片/视频 → 成片）

**入口**：新建视频 → 「从素材开始」组（素材增强 / 真实素材混剪）。

1. 拖拽或点击上传素材（多选、列表可单删）。
2. 填视频标题（可选）、目标时长、制作目标说明。
3. （可选）素材高级设置：BGM、声音、语速。
4. 「开始生成」→ 先上传素材再建任务，按钮显示「正在上传并提交…」。
5. 之后与动线 A 第 5-7 步相同。

## 4. 动线 C：数字人与特效（图生视频 / 动作迁移 / 数字人）

**入口**：新建视频 → 「数字人与特效」组，或 `/create/special/:mode`。

1. 顶部三个模式按钮切换；模板摘要显示可用状态。
2. 按模式上传输入（图片 / 参考视频+图片 / 人物形象+商品图或自定义文案）。
3. 「开始生成」→ 任务进任务中心，页内也有状态卡。
4. 完成后同 A6-A7。

## 5. 动线 D：批量生产（N 条内容 → N 条片）

**入口**：新建视频 → 「批量生产」，或 `/create/batch`。

1. 选「批量选题」或「批量文案」模式。
2. 粘贴内容：选题一行一条；文案用 `---` 分块（第一行为标题）。
3. 下方**解析预览**实时刷新：序号、标题、字数，可单条删除；格式问题提交前就能看见。
4. （选题模式）填分镜数量、标题前缀。
5. **生产提交面板**：选生产模板（只列兼容模板，默认为项目默认）→ 只读的模板默认摘要 chips（画面/声音/BGM/拆分）→ 需要长期改默认点「调整默认 → 设置」；仅本次微调则开专家模式展开「本次覆盖」。
6. 「开始批量生成」→ 确认弹窗「创建 N 个生成任务？」（提示额度消耗）→ 确认。
7. toast「批量任务已创建（N 条）」；每条任务注册进任务中心；右栏批次状态卡逐条显示进度，失败项可单条重试。

**完成判据**：任务中心 N 条任务逐个转为已完成；批次卡失败数为 0。

## 6. 动线 E：多语言审核出片（选题 → 人工确认稿 → 多语言成片）

**入口**：新建视频 → 「从文字开始」组的多语言审核卡，或 `/create/script-review`。三步 Stepper，可回退。

**第 1 步 · 生成草稿**
1. 填选题（一行一条）；点选语言 chips（中文/English/日本語/한국어/Español/繁體中文），可补自定义语言。
2. （可选）换脚本/分镜 Prompt 模板与模型；Bazi 模板自动做中英 Prompt 映射（英文变体不出现在下拉里）。
3. 「生成审核草稿」→ 完成后自动进第 2 步。中断后回来可从「最近审核草稿」列表点选恢复（同样跳到第 2 步）。

**第 2 步 · 逐条审核**
4. 每个选题一张卡：「参与生成 / 跳过」；每种语言一块：「生成 / 不生成」开关 + 标题 + 完整文案 + 分镜文案（一行一个，实时计数）。
5. 已勾选语言若文案或分镜为空，就地标红；有错时「下一步」被挡。
6. 「保存审核修改」持久化（草稿是资产，改完可以明天再继续）。

**第 3 步 · 提交生成**
7. **生产提交面板**（与批量同一组件）：选生产模板 + 默认摘要；流程强制项注明"按行拆分分镜、每语言 Fish 配音"。
8. 每语言 Fish 音色卡：reference_id（中文自动带系统默认）+ 语速滑杆；缺 reference_id 行内标红并挡提交。
9. 数量预告「将生成 N 条视频（已审核选题 × 勾选语言）」。
10. 「提交生成视频」→ 每条进任务中心（命名「文案审核 · 选题 · 语言」）；批次卡显示状态；「前往任务中心」按钮引导离开。

**完成判据**：任务中心出现 N 条审核任务并逐个完成。
**复用路径（P1 计划）**：同一批确认稿换模板再次出片，不重新生成/审核。

## 7. 横切动线 F：跟踪 → 作品 → 发布

**任务中心**（任何时刻）
- 侧边栏「任务」带运行中角标；列表每条：状态徽章、模板名、提交时间、进度条；运行中可取消，已完成有「查看与发布」，终态可从列表移除。
- 空态给「新建视频」按钮。

**作品库**
1. 网格卡片：成片缩略、标题、状态、时间；顶部按标题搜索；筛选排序收在折叠区。
2. 点卡片 → 右侧详情：成片播放、输入参数、分镜帧、下载。
3. 详情头部「发布」按钮（仅完成态）→ 发布抽屉：平台多选（Buffer channels）、标题（YouTube 校验）、caption + hashtags、立即入队/定时（时区）、「检查配置」逐项验证 → 「提交发布」→ toast + 发布记录；再次进入显示「再次发布」。
4. 删除走确认弹窗（提示会删文件）。

**完成判据**：发布记录出现在详情中；Buffer 后台可见排期。

## 8. 横切动线 G：三层配置（"设置管接入，模板管默认，表单管这一次"）

| 想改什么 | 去哪里 | 生效范围 |
| --- | --- | --- |
| 服务能不能用（Key/URL/音色库） | 设置 → 系统设置 | 全局 |
| 这条生产线以后每次的画面/声音/BGM | 设置 → 模板状态 → 模板卡「默认生成配置」（专家模式） | 该模板的所有后续出片：单条、批量、审核、agent 全部生效 |
| 只改这一次 | 各创作页的高级设置 / 提交面板「本次覆盖」（专家模式） | 仅本次提交 |

**验收动线**（回归必测）：设置里把日常模板 BGM 音量改成 35% → 不做任何页面内覆盖，从单条、批量、审核各出一条片 → 三条任务的参数全部是 35%。

## 9. 反馈与状态约定（全动线通用）

- **成功/后台事件** → toast（提交成功、生成完成/失败、已保存、已复制）。
- **表单问题** → 就地红字/InlineError，按钮禁用时下方一行原因。
- **破坏性操作** → 确认弹窗（删除、批量提交、跨入口切换）。
- **等待** → 进度条 + 阶段文案；离开页面不丢（任务中心兜底）。
- **排障** → 每张任务/结果卡的「技术详情」折叠区（任务 ID、pipeline、路径）。

## 10. 已知边界（预期内的"不顺"）

- 审核确认稿暂不能二次出片（P1）；批量条目不能转入审核流（P2 内容库）。
- 作品库缩略图依赖成片可访问，运行中/失败任务显示占位图标。
- 发布依赖 Buffer 配置，未配置时「检查配置」会给出具体缺项。
- Action Transfer 需真实用户素材，E2E 验收未通过前视为实验性入口。
