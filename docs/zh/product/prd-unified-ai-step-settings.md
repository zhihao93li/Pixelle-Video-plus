# PRD：统一 AI 步骤设置与提示词库

## 文档状态

- 状态：已实现并通过自动化验收
- 版本：v1.1
- 适用范围：模板设置、本次设置、提示词库、LLM 模型资源

## 一、目标

解决当前提示词只能选择和查看、不能当场编辑的问题，并把所有用户可控制的 LLM 创作环节统一为同一种交互。

每个 AI 步骤只包含两类设置：

1. 使用哪个模型。
2. 给模型什么提示词。

写稿、分镜和后续新增的长文改写等创作步骤复用同一个产品合同，不再分别发明“写稿手册”“分镜手册”等概念。

## 二、核心原则

- 不提供自动选择、自动推荐或后台静默切换模型。
- 模型与提示词在界面中成组展示，但数据上保持独立。
- 用户可以从已有提示词中选择，也可以在当前位置直接编辑正文。
- 提示词库用于整理和复用，不是编辑提示词的必经入口。
- 系统内部用于格式校验、修复和安全限制的提示词不向用户开放。

## 三、统一交互

每个可配置的 AI 步骤展示：

```text
模型
[模型提供方 ▼] [搜索或选择模型 ▼]

提示词
[已有提示词 ▼] [展开编辑]
[提示词正文编辑器]
```

### 3.1 模型选择

- 第一级选择真实的 LLM 服务，例如“AiHubMix 主账号”或“OpenAI 直连”。LLM 服务必须拥有独立配置、凭据和实际调用路径，不能根据模型名称猜测。
- 第二级只展示该提供方下的模型，并支持输入搜索。
- 切换提供方后，如果当前模型不属于新的提供方，则清空模型，要求用户明确选择。
- 未读取到模型目录时允许直接填写模型标识，但必须明确这是手动输入。
- 界面始终显示最终选择，不存在“自动选择”。
- 设置中心允许配置多个 LLM 服务；同一种 Provider 也可以配置多个账号。
- 每个步骤保存 `LLM 服务 ID + 模型 ID`。通过 AiHubMix 使用 GPT 时，Provider 仍然是 AiHubMix，不能显示为 OpenAI 直连。

### 3.2 提示词选择与编辑

- 下拉框列出内置和自定义提示词。
- 选择提示词后可以立即展开正文。
- 正文可以在当前页面直接修改。
- 修改内置提示词不会覆盖系统原版，而是成为当前范围的自定义正文。
- 用户可以主动“另存为提示词”，保存后进入提示词库。

### 3.3 保存范围

- 本次设置页的修改只写入当前生产任务。
- 模板设置页的修改保存为当前模板的长期默认。
- “另存为提示词”只负责加入提示词库，不自动改变其他模板。
- 存在正文覆盖时必须显示“自定义正文 · 不跟随提示词库”，并提供“恢复跟随模板”。

### 3.4 多语言覆盖

- 不允许输入“语言=模型”配置语法。
- 使用“语言 + LLM 服务 + 模型”的结构化行编辑器。
- 支持添加和删除语言行；每一行都保存真实的 LLM 服务 ID 和模型 ID。

## 四、提示词库

设置中新增“提示词库”，统一管理用户保存过的创作提示词。

支持：

- 按写稿、分镜分类查看。
- 新建提示词。
- 复制内置提示词。
- 编辑自定义提示词。
- 改名自定义提示词。
- 删除未被模板引用的自定义提示词。
- 查看提示词正文以及内置/自定义来源。

内置提示词只读；用户修改时必须复制为自定义提示词。

## 五、命名调整

| 旧名称 | 新名称 |
| --- | --- |
| 写稿手册 | 写稿提示词 |
| 分镜手册 | 分镜提示词 |
| Short Oral Script | 简短口播文案（界面显示名） |
| Copy-Safe Scene Split | 忠实原文分镜（界面显示名） |
| 按语言指定写稿模型 | 多语言模型覆盖 |

## 六、数据合同

- 提示词模板继续拥有稳定名称、类型、正文和来源。
- AI 步骤同时保存所选提示词名称和可选的正文覆盖。
- 正文覆盖优先于提示词模板；没有正文覆盖时才读取所选模板。
- 模型目录按照提供方分组，但模型值仍保存为真实模型标识。
- 模型目录由每条真实 LLM 服务自己的接口读取；读取失败必须显示失败原因，不能用静态品牌表替代。
- 同一提示词可以搭配任意模型，不因切换模型复制提示词。

## 七、非目标

- 不建设模型自动选择或推荐系统。
- 不把提示词与模型永久绑定为一个预设。
- 不开放系统内部协议提示词。
- 不建设复杂的提示词版本审批、团队权限或发布流程。

- [x] 写稿和分镜使用同一种“模型 + 提示词”交互。

- [x] 切换提供方不会静默保留不属于该提供方的模型。
- [x] 提示词可以在模板页和本次设置页直接展开编辑。
- [x] 本次设置中的正文修改只影响当前任务。
- [x] 模板设置中的正文修改可以保存为模板默认。
- [x] 内置提示词不会被直接覆盖。
- [x] 用户可以把当前正文另存为自定义提示词。
- [x] 设置中存在可用的提示词库管理页面。
- [x] 自定义提示词支持新建、编辑、复制和删除。
- [x] 被模板引用的提示词不能直接删除，并显示明确原因。
- [x] 提示词库不是修改提示词的必经入口。
- [x] 没有自动模型选择、自动推荐或静默回退。
- [x] 现有写稿和分镜生成在没有正文覆盖时保持原行为。
- [x] 设置中心支持新增、编辑、启用、删除多个真实 LLM 服务并指定系统默认。
- [x] AiHubMix、OpenAI 直连等服务使用各自独立地址和密钥，不根据模型名猜 Provider。
- [x] 多语言模型覆盖使用结构化行编辑，不再输入“语言=模型”。
