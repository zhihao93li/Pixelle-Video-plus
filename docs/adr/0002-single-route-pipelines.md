# ADR-0002：一条 Pipeline 只有一种输入和固定路线

- 状态：已采纳
- 日期：2026-07-16

## 背景

同一 Pipeline 通过“入口”跳过开头或结尾步骤，会让设置展示、确认站、失败恢复和 Agent 能力都依赖隐藏分支，用户无法从生产方式判断实际路线。

## 决策

一条 Pipeline 声明一种输入合同、一组有序阶段和一组必需产物。输入、必经阶段或产物不同就注册另一条 Pipeline；相同的 Provider、配音、画面和合成能力继续复用底层服务。

不传递 `entry`、`start_stage` 或 `skipped_stages`。模板只能绑定一条 Pipeline 并保存默认设置，不能改变路线。

## 后果

- 用户选择生产方式后，路线和可配置阶段可预期。
- Pipeline 数量会增加，但每条合同更简单，恢复和验收可以独立进行。
- 是否存在某条路线以自动生成合同和运行时 capabilities 为准。
