# ADR-0004：人工确认与 Agent 边界

- 状态：已采纳
- 日期：2026-07-16

## 背景

确认是生产路线中的人工站点。若 React 与 Agent 各自维护确认逻辑，容易出现版本不一致、重复确认或 Agent 未展示完整内容就代替用户批准。

## 决策

人工确认由后端版本化待确认对象拥有，React 和受支持的 Agent 对话消费同一对象。确认必须提交精确的 review ID、内容版本与明确确认事实；编辑、重写、局部重做或整套重做都会生成新版本并使旧确认失效。

Agent 配图先提交纯文本分镜和图片提示词，确认后才生成并上传图片。图片齐全后原生产任务自动继续，不建立第二次生产。

## 后果

- 用户可在 React 或 Agent 中确认，但两端状态同步且不能重复批准旧版本。
- 未确认前不消耗图片生成资源。
- Agent 能做什么以运行时 capabilities 为准，界面和文档不扩大权限。
