# ADR-0001：可执行合同与自动生成事实

- 状态：已采纳
- 日期：2026-07-16

## 背景

Pipeline、模板、设置和状态曾同时出现在代码、前端、PRD 与说明文档中。多轮修改后，手工副本会失去同步，造成界面漏项、过时概念继续影响实现，以及 Agent 依据旧文档操作。

## 决策

代码级事实由 Pydantic Schema、Pipeline Manifest、内置模板注册表和生产任务模型拥有。仓库提交由它们确定性生成的 `docs/generated/system-contract.json` 与 `.md`；CI 重新生成并比较，存在漂移时失败。

运行时 Provider、凭据、启停和可用性不写入仓库，分别读取 `/api/agent/capabilities`、`/openapi.json` 与健康检查。产品文档只解释用户语义，ADR 只解释取舍原因。

## 后果

- 修改合同必须同时让生成物通过 CI，不能只改某个页面的副本。
- 自动生成文件禁止手改，也不包含本机配置或秘密。
- 测试数据仍可构造场景，但不能冒充运行时能力事实。
