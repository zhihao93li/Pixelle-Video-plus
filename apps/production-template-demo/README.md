# Pixelle Production Template Demo

React + Vite + shadcn/ui demo for the Pixelle production-template workspace.

This demo is intentionally separate from the existing Streamlit UI. It explores
the product surface described in:

- `docs/zh/product/pixelle-production-template-productization-prd.md`

## Scope

The demo covers:

- Current production line visibility.
- Production template switching.
- Project default production line state.
- Content input for topic/script/storyboard.
- Asset manifest preview.
- Task preview, quality policy, and recent generation summary.

It does not call the real Pixelle backend yet.

## Commands

npm install
npm run dev
npm run typecheck
